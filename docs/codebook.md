# Codebook

Variable-level documentation for staged analysis files. Entries are added as
definitions change or need explicit conventions recorded. Methodological
figure notes live in `outputs/figures/README.md`.

## Hospital characteristics tables

Generated by `analysis/20_hospital_characteristics.R` using the same cleaned POS
panel and exact CCN/event-year matches as the existing characteristics table.
The default input is `data/processed/pos_panel_reconciled.csv`, consistent with
`run_project.R`. Opening/closure characteristics use event-year observations,
regardless of the active flag. Non-event observations require active = 1, no
opening/closure in that year, and certified beds > 1 or missing. The study
window is 2010–2023; 2009 is excluded. Header N counts unique CCNs within groups;
the descriptive statistics summarize hospital-years. A CCN can appear in more
than one group over time. The no-location and location versions use the same
sample and shared estimates; unmatched rural classifications do not remove
observations from the other characteristics.

| Characteristic | Definition |
| --- | --- |
| For-profit | POS `control` = 4 or 9 |
| Nonprofit | POS `control` = 1 or 2 |
| Public | POS `control` = 5, 6, 7, or 8 |
| Other/unspecified | POS `control` = 3 (CMS "Other"; retained in the sample since October 2026) |
| Major affiliation | POS `medschool` / CMS M11 = 1 |
| Graduate-school affiliation | POS `medschool` / CMS M11 = 3 |
| Limited affiliation | POS `medschool` / CMS M11 = 2 |
| No affiliation | POS `medschool` / CMS M11 = 4 |
| Rural or small-town location | Hospital ZIP matched to 2010 primary RUCA 7–10; metropolitan/micropolitan = 1–6 |
| Certified beds | Mean of nonmissing `certbeds` |

CMS M11 describes the extent of medical-school affiliation for graduate medical
education (physician residency training). Graduate-school affiliation represents
the most extensive involvement, typically within a university academic medical
center; major is the next level, followed by limited and no affiliation.
These categories do not use resident-to-bed thresholds or membership criteria.
See [CMS Exhibit 286, M11 and M13, PDF pages 3 and 15](https://www.cms.gov/Regulations-and-Guidance/Guidance/Transmittals/Downloads/R80SOMA-.pdf).

The old `teach_major` indicator equals M11 code 1. The old `teach_majgrad`
indicator equals codes 1 OR 3, so its former “Graduate Teaching” row overlapped
with major teaching. The revised four-category block uses `medschool` directly
and sums to 100% before rounding. Limited affiliation is not treated as
non-teaching. The RUCA definition follows `analysis/baseline_urbanicity_split.R`
and describes hospital ZIP location, not the HSA's aggregate urbanicity.

Each main table has one overall p-value column. Ownership and teaching receive
one test per categorical block, rural location one binary test, and mean beds
one continuous test. Categorical tests use `survey::svychisq(statistic = "F")`
with unit observation weights and CCN clusters across all years/groups. This is
the second-order Rao-Scott adjustment to Pearson chi-square, evaluated using an
F approximation, not the ordinary independent-observation chi-square test.
Mean beds use the joint test of both event-status coefficients in a three-group
linear model, with `sandwich::vcovCL(type = "HC1", cadjust = TRUE)`, 2 numerator
degrees of freedom, and G−1 denominator degrees of freedom for G hospitals.
See the [survey documentation](https://search.r-project.org/CRAN/refmans/survey/html/svychisq.html).
Tests are unadjusted for covariates and multiple testing; they do not identify
which pair differs. Missing values are excluded per characteristic.

Outputs include raw category counts/expected counts, denominators/missingness,
test methods, adjusted F statistics, degrees of freedom, and full-precision
p-values. The separately labeled raw Pearson statistic is diagnostic only.
Percentages/means are formatted to one decimal without rounding input to tests;
p-values use three decimals or `<0.001`. Year-weighted sensitivity tables remain
descriptive and do not reuse the main table's p-values. Their non-event annual
means are weighted by the opening/closure event-year distributions, with weights
normalized over years with nonmissing estimates.

`outputs/manuscript/hospital_characteristics_methods.md` supplies manuscript
methods text for either main version, including optional rural-location wording.
Both main TeX versions and both sensitivity versions are staged there as well.

Standalone tables use a bold `Table 1.` caption; the manuscript builder supplies
the same label in the compiled figure bundle. Caption settings are inside the
table body so they also apply when an external wrapper strips its preamble.
The concise table note states the event coverage relative to Figure 1. Each run
reconciles the curated event lists against the selected panel by exact CCN/year,
then diagnoses missing matches against raw POS and the cleaning name lists.
`hospital_characteristics_event_coverage.csv` saves aggregate counts and input
hashes. Missing CCNs and missing event-year observations are distinguished from
specialty, ownership, and manual exclusions; any remaining loss is reported as
another eligibility exclusion. No adjacent-year data substitution or identifier
correction is performed. Long affiliation definitions and statistical details
are preserved in the methods file rather than repeated in the table note.

## `data/interim/ntl_hsa_percentiles.csv`

### `certbeds_per_1000_residents_lag1`

HSA-level certified beds per 1,000 residents attributed to staged year `t`.
Built in `cleaning/04_stage_national_percentiles.R`.

| Year(s) | Numerator | Denominator | Denominator source |
|---|---|---|---|
| 2010 | 2009 certified beds | **2010 population (contemporaneous, NOT lagged)** | 2010 Decennial Census (SF1 P1) |
| 2011 | 2010 certified beds | 2010 population (lagged) | 2010 Decennial Census (SF1 P1) |
| 2012-2023 | year `t-1` certified beds | year `t-1` population (lagged) | ACS 5-year, HSA-aggregated (`sum_total_pop_event`) |

**2010 flag — contemporaneous denominator.** The 2010 observation is the only
year in the series whose denominator is not lagged: it pairs 2009 beds with
the 2010 Decennial Census population, because no 2009 population source exists
in the pipeline. Treat comparisons of the 2010 value against later years
accordingly.

Numerator: certified beds summed over active hospitals in the cleaned POS
panel (`data/processed/pos_panel_reconciled.csv`), ZIP-to-HSA via
`ZipHsaHrr.csv`. HSA-years where no active hospital reports beds are NA (not
zero). 2009 POS rows exist solely as the lag source for the 2010 numerator and
never appear as observation years.

Census denominator: built by `cleaning/03b_clean_census2010_pop.R`
(`data/processed/hsa_census2010_pop.csv`), ZCTA P001001 aggregated to HSA with
the same crosswalks and deduplication as the ACS population.

### `certbeds_per_1000_residents`

Contemporaneous (unlagged) companion column: `1000 * beds_t / pop_t`. For 2010
the denominator is the 2010 Decennial Census population; 2011-2023 use ACS
5-year denominators. This column is an intermediate; the lagged column above
is the variable of record for ranking and analysis.

### `population_density`

HSA residents per square mile: HSA-summed population over HSA-summed ZCTA land
area (`data/processed/zctas_with_area.csv`), built in
`cleaning/10_rebuild_ntl_hsa_percentiles_from_raw.R`.

| Year(s) | Population source |
|---|---|
| 2010 | 2010 Decennial Census (SF1 P1), ZCTA-level |
| 2011-2023 | ACS 5-year `B01003`, ZCTA-level (`sum_total_pop_event`) |

Both sums are restricted to the same area-complete ZCTA set (rows with
non-missing area and non-missing population), so the 2010 value is
compositionally consistent with 2011+. Density is a level, so the Census
substitution follows the same logic as the beds-per-1,000 denominator above.

### `pop_change_pct`

Trailing population change for staged year `t`:
`100 * (pop_{t-1} - pop_{t-3}) / pop_{t-3}`, over ACS 5-year HSA populations
(`sum_total_pop_event`). **First valid year: 2014** (needs the 2011 ACS value
as the `t-3` lag).

**Deliberately not extended with the 2010 Decennial Census.** An ACS 5-year
estimate behaves like a population level at its window midpoint, so the
ACS-only formula compares midpoints roughly two years apart. The only value
the Census could add is 2013 = (ACS 2012 - Census 2010) / Census 2010; ACS
2012 (2008-2012) has midpoint ~2010 and the Census is April 2010, so that
"change" would span roughly zero years and be biased toward zero relative to
every other year, ranking 2013 events artificially near the middle of the
growth-percentile distribution. `sum_total_pop_event` is left NA for 2010 in
the rebuild so the lag-based formula cannot pick the Census value up. The
Census is used only for level variables (beds per 1,000, urbanicity weights,
population density).

## `data/interim/opening_closure_nonevent_percentiles.csv`

### `certbeds_per_1000_residents_percentile` (and `_geo`, `_geo_zip_count` variants)

Within-year percentile ranks of `certbeds_per_1000_residents_lag1`, built in
`cleaning/06_stage_openclose_percentiles.R`. Populated 2010-2023; the 2010
pool inherits the contemporaneous-denominator convention flagged above.

### `pop_change_pct_percentile`

Within-year percentile ranks of `pop_change_pct`, built in
`cleaning/06_stage_openclose_percentiles.R`. Populated 2014-2023 only, because
the underlying trailing ACS population-change measure first becomes valid in
2014. `analysis/33_beds2010_decile_events.R` converts the 2014 percentile to
ten fixed baseline deciles for `popchange_decile_events_by_poverty.png`; its
2014-2023 event window is therefore a data-availability restriction, not a
separate sample-selection choice. The 2014 population-change value is the
change from the 2011 to 2013 ACS population estimates.
